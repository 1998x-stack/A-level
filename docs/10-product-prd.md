# 10 · LeetMath A-Level 数学产品 PRD 与阶段路线

**版本**：v0.1（2026-11-18 研究草案）。本计划尚未获得学校用户验证，时间与题量是目标，不是已完成交付。

## 1. 产品定位

LeetMath A-Level 不应该是“又一个 Past Papers PDF 下载站”，而是把考试局正确的考纲、按小问结构的原创或获授权数学题、可解释的数学判分、Anki 式复习和教师布题工作流结合起来。

目标课程路径：上海初中/中考 → 国际高中入学数学 → IGCSE/Pre-A → CAIE AS/A2（9709）→ Further Maths（9231），之后扩展 Edexcel IAL 与 OxfordAQA。

## 2. 角色与使用场景

| 用户 | 核心需求 | 关键使用路径 |
| --- | --- | --- |
| AS 学生 | P1/P4/P5 考纲章节训练 | 选 topic → 做题 → 看小问分数 → 错题复习 |
| A2 学生 | P3/P6 综合题与真实评分规范 | 作答 → 多规则评分 → 分步反馈 |
| 9231 学生 | 高级代数、矩阵、复数、力学 | 公式输入 + 可视化 + 复杂答题 |
| 上海转轨学生 | 中英数学术语、入学数学 | 桥接训练 → 按弱点补习 |
| 教师 | 组题、布置、批改、分析 | 考纲筛选 → 题单 → 班级学情 |
| 校方 | 权限、合规、课程配置 | 多租户题库 → 教师/学生角色管理 |

## 3. 练题页面需求

顶部显示明确的进度和成绩：第 N/总题数、已完成小问、当前得分/总分、计时、提交状态。主区域展示中英切换题干、数学公式、图片/可视化；按 (a)(b)(i) 多层小问作答。答题类型包括数值、代数式、区间集合、矩阵向量、选择题与书面步骤。

提交时先保存，再判分；不允许因 Renderer 超时自动记为 0。评分反馈按小问展示：正确/不正确/待老师审核、分数、可接受数学表达、错误类型和下一次复习计划。对不可判分的证明题提供教师审核入口。

### 3D/Manim 设计

- 2D 函数和解析几何：可调整参数、点、切线、图像。
- 立体几何与空间向量：Three.js 多视角旋转、辅助平面与投影。
- 力学：位移、速度、力和能量模型随参数变化。
- Manim：可解释演算与概念动画；视频由已审核教学参数生成，必须保留源代码/版本/渲染日志。
- 可视化应来自同一数学参数模型，不能仅贴通用示意图代替精确题目。

## 4. 复习调度

沿用 Anki 式 due/interval/ease 的思想，但同时保留 topic mastery（小问得分、错因、重试、提示次数、用时）。一题可以对应多个知识点；复习可以重新生成合法 seed 题实例，避免机械记忆固定答案。每次生成都保留题面快照，保证可回顾。

## 5. 教师端

教师按 board、syllabus、component、topic、难度和评分类型筛题；创建原创题、题单、班级作业及模拟卷；看到错误类别、各知识点掌握度和机器评分不确定性。允许配置教师签核流程，但**评分证据必须真实可追溯，版权/校内权限检查不受默认签核策略影响**。

## 6. 来源与内容质量

四类内容：original、licensed、external_index、private_school。题目入库前分别做数学正确性、图形语义、考纲归属、语言/术语、版权范围、评分规则审核。官方真题仅创建 URL 索引，除非另有明确适用授权。

## 7. 系统建议

~~~text
Web: 现有 LeetMath 前端 + MathJax/KaTeX + 2D/Three.js
Backend: LeetMath API + PostgreSQL + search + object storage
Graders: SymPy + PG Renderer adapter + step rules + teacher review
Media: Manim service, MP4 and source/seed/version manifest
Content:原创题 + 授权题 + 官方索引 + OPL 元数据审计
~~~

需要先审计现有 LeetMath 实际代码和数据库，勿在未经确认时假设已存在所有组件。

## 8. 阶段任务

| 阶段 | 建议内容 | 周期估算 | 交付物/通过条件 |
| --- | --- | --- | --- |
| Phase 0 | 版权许可清单、9709/9231/IAL 考纲、学校访谈、LeetMath schema 对照 | 1–2 周 | Source Registry、topic tree、访谈纪要 |
| Phase 1 | 9709 P1/P3、300–500 道原创题目标、练题页面、错题复习 | 4–6 周 | 题目 QA、可评分小问、学生端 MVP |
| Phase 2 | 9709 P4/P5/P6、9231、Pearson IAL、PG 判分实验 | 4–6 周 | 课程版本、合法卷组合、seed 可重放、判分基准 |
| Phase 3 | 国际高中入学数学/IGCSE 桥接、教师组卷、学校试点 | 约 4 周 | 教师反馈、班级学情、实际试点数据 |
| Phase 4 | 适应性推荐、Manim/3D、AI 步骤解释和成本监控 | 持续 | 数学/视觉审阅、监控、用户效果数据 |

## 9. MVP 验收指标

- 考纲映射覆盖与准确性；题目可追溯来源和许可证完整率。
- 数学答案验证：常见数值、等价式、定义域、精度、格式、部分得分。
- ≥200 个测试案例建立误给分/误拒分基线；复杂数学证明可转教师。
- 权限与故障测试：未授权题不可见、超时不丢提交、多租户隔离。
- 学生端：完整做题、复习、分数反馈；教师端：真实创建题单和布置作业。
- 需求验证：至少 3 所学校访谈并争取 1–2 个小规模试点（目标，不是已签约）。

## 10. 商业模式假设

免费个人版（原创题、错题）；个人增强版（智能复习、可视化）；教师版（组卷、批改、学情）；学校部署版（私有题库、权限、机构数据）。价格、用户数与付费意愿均待验证，当前不输出未经证实的市场规模。

## 11. 非目标

不做侵权真题镜像；不绕过第三方限制；不把 PG 等价答案当作完整数学证明；不直接宣称 OPL 全量可商用；不把学校名单当成已经获得的客户。
