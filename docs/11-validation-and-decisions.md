## 3. 架构决策记录（ADR）

**ADR-001：先 CAIE 9709**（建议采纳）。原因：考纲、章节与卷组合清楚；如果学校访谈显示 Pearson IAL 更主要，应调整优先级。

**ADR-002：真题默认只做官方索引**（强制基线）。来源可读取不等于有再发布许可。合法公开内容以原创题和明确授权为主。

**ADR-003：PG Renderer 是可选 Adapter**（待真实验证）。LeetMath 保留用户、作业、练题、复习、数据库；PG 提供随机生成/数学比较，失效时可回退 SymPy/教师复核。

**ADR-004：模板、实例、作答与评分分离**（建议采纳）。保证变体训练和历史重放。

**ADR-005：教师签核与版权独立**（强制基线）。可以按学校流程配置默认教师通过，但不能伪造教师已人工看过的证据，也不能让未授权题目发布。

## 4. 判分反例与视觉基准

- 代数等价：(x+1)² 与 x²+2x+1。
- 定义域差异：(x²−1)/(x−1) 与 x+1；x=1 必须考虑。
- sqrt(x²)=|x|，不能无条件等于 x。
- 数值精度：1/3 与 0.333；根据题目要求决定。
- 多答案顺序：两个方程根可能允许调换。
- 方法与结果分离：结果正确但方法证明不充分；需 M/A/B 分项。
- 随机参数造成退化几何对象、零分母等场景。
- 3D 视角切换不能改变客观几何关系。
