# 02 · 上海 A-Level 学校生态、目标用户与访谈计划

## 1. 研究目的

上海国际学校和国际高中并不是一个单一市场：民办双语学校、国际课程中心、外籍人员子女学校在招生资格、课程、家长需求、校内教学和采购决策上可能完全不同。LeetMath 初期应聚焦**有明确 A-Level 数学授课场景**的项目，而不是把所有“国际学校”都视为 CAIE 数学客户。

## 3. 重点用户细分

| 用户 | 首要任务 | 产品机会 |
| --- | --- | --- |
| 上海中考后转国际课程学生 | 术语与知识体系转换 | 中文/英文术语卡、Pre-A 桥接题 |
| AS 阶段学生 | 适应英语题干、章节进度 | P1 + P4/P5 章节训练 |
| A2 学生 | 高阶综合题与考试分数 | P3/P6 多小问、分步得分 |
| Further Maths 学生 | 抽象数学和高难计算 | 9231、PG 模板、复杂可视化 |
| 教师 / 数学教研组 | 布题、批改、反馈与分层 | 教师题单、班级分析、审核 |
| 家长 / 个人考生 | 了解能力缺口与自主复习 | 练习记录、阶段报告、官方资源索引 |

## 4. 学校访谈提纲

至少访谈 3 所学校，尽可能覆盖不同考试局；再访谈 8–12 位学生与 3–5 位一线数学老师（为**目标样本**，不是既有访谈结果）。

建议提问：

1. 使用哪一考试局、哪一科目代码、哪个考纲年份？是否按学年变更？
2. 采用哪些课本、Past Papers、Topical Questions 和校内题库？哪些授权可允许第三方平台使用？
3. 作业是纸笔、PDF、Google Classroom/LMS 还是其他系统？评分由谁完成？
4. M/A/B 类部分得分中，教师最希望自动化的是哪些题型？
5. 中文讲解是否帮助学生？数学公式输入和手机端训练是否是障碍？
6. 常见错因是基础知识、英语理解、计算错误还是思路缺失？
7. 进入学校采购流程的最低要求是什么？是否可先进行免费教师试点？
8. 学生隐私、校内数据权限和未成年人数据处理有哪些要求？

## 5. 学校试点定义

- 试点 A：一个 CAIE 9709 P1 班，教师发布两周原创专题练习；记录组卷时间、参与率、答案正确率、教师修正率。
- 试点 B：国际高中入学数学桥接练习，测术语与基础概念转换的完成率。
- 试点 C：教师对机器判分与人工判分做双盲复核，专门收集错误给分和不合理拒分。

只有完成上述校方验证后，才适合估算上海 TAM/SAM、付费率和校方采购意愿；不能用学校数量代替学生数。
